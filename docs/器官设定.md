## 冰火器官文案 · 依据本体（脆二1.2）改写
对照基准：脆二1.2/kubejs/assets/kubejs/lang/zh_cn.json 的 1135 条 tooltip；效果来源：冰火器官表(1)-1(1).xlsx。
覆盖范围：冰火器官表(1)-1(1).xlsx 全部 99 件（火龙 / 电龙 / 冰龙 / 炼狱 / 风暴 / 凛冬 各 13 件，异兽 21 件）。
### 改写规则
1. 主语三选一：器官自身行为写「该器官」，属性加成写「你的 X」，玩家行为写「你」
2. 量纲三分：固定值用「点」，百分比用「%」，乘法用「倍」/「倍率」；不用「加成」当动词
3. 动词池：提供 / 获得 / 提高 / 造成 / 等同于 / 赋予，不用「加成」「提升」
4. 一条一事：一条 ★ 只承载一个因果链（触发 → 效果 → 缩放可用逗号连），互不相干另起一条
5. 纯属性器官不给机制行：属性已由分数栏显示，只写风味句（本体 39 件如此，如龙血肺、龙血肌肉）
6. 术语在落地时染色（§6术语§r），本文用「」标注；术语释义统一收进文末术语表
7. 数值必须写明：本体是量化到底的，换算关系、上限、次数、范围全部写死，不用「少量」「一些」「有概率」这类模糊词
8. 四种量化句式（全部取自本体原文）：
   - 换算：胸腔的每 %s 点健康会提供 %s 点最大生命值
   - 上限：（最高为 %s 点） / 最高不超过 %s 点 / （最高 5 级）
   - 次数：每种食物仅可触发该效果一次 / 最多一次生成 %s 个
   - 范围：在器官左右方向两格内 / 周围 16 格
   - 等级：效果最高到 4 级 / （最高 5 级）
   - 冷却：会陷入 3 分钟冷却
9. 数值上色：走 %s + Text.gold('值')，固定值时直接写 §6N§r；术语同样 §6…§r，两者同为金色
10. 属性面板可见项照写：暴击率、攻速、护甲这些虽然面板能看，但器官给的是条件性增量（触发时 +6%、叠层 +5%），必须写明，否则玩家算不出收益

### 显示层级（照本体实际渲染）

## 九、本体 tooltip 的显示栈（哪些自动、哪些要写）
照两张游戏内截图逐行拆解，一件器官的 tooltip 由上到下共 8 层：

因此只有 ④ 和 ⑦ 需要产出，③⑥⑧ 一律不要写进语言文件。
对照实证（本体 king_of_stomach）：
```js
.addDefault(Text.translatable('tooltips.kubejs.king_of_stomach.default.1').gray())
.addAlt(Text.translatable('tooltips.kubejs.king_of_stomach.alt.1'))
.addAlt(Text.translatable('tooltips.kubejs.king_of_stomach.alt.2', Text.gold('0.25')))
.addCtrl(GulaSlotType)                                    // ← 「    ■ 消化」
.addCtrl(Text.translatable('tooltips.kubejs.king_of_stomach.ctrl.1'))
`
语言文件：
```json
"tooltips.kubejs.king_of_stomach.default.1": "它保管着所有食物以供不时之需！",
"tooltips.kubejs.king_of_stomach.alt.1": "    §6★§r 胸腔内拥有的食物将会提高你§6最大生命值§r和§6攻击力§r",
"tooltips.kubejs.king_of_stomach.alt.2": "    §6★§r 食物提供的每点饥饿度将会提高 %s 点生命值上限",
"tooltips.kubejs.king_of_stomach.ctrl.1": "        §6★§r 大胃王因食物提高…的效果将会翻倍"
`
注意三件事：★ 前有 4 空格、★ 用 §6 上色、数值走 %s 且由 Text.gold() 传入（数字和术语同为金色，不是白色）。
## 十、落地说明
1. 键名规则（与本体一致）：
   item.kubejs.icefire_<id> / tooltips.kubejs.icefire_<id>.default.1 / .alt.N / .ctrl.N
2. 纯属性器官不注册 tooltip：火龙 / 电龙 / 冰龙 的 12 件基础件（除晶核）共 36 件，只保留 item.* 名称键，addDefault 之外不调 addAlt；风味句需要单独接一条 addDefault 才可见
3. 标题行：龙枢段落用 addCtrl(DragonPivotType)，异兽「激活」段落的标题需你定槽位常量
4. 数值占位：本文保留的数字均为原文数值，未做平衡调整。若要改成 %s 动态传值（本体 45% 的做法），代码里必须写 Text.gold('值')，否则数字会掉成白色
5. 字面百分号要写 `%%`：语言文件里凡是最终显示 % 的，一律写 %%（本体 11 处如此，其中 6 处不含 %s 也照样写）；正文里不带数字的百分比已全部改为定性描述，因此剩下的 %% 只会出现在术语表里
6. 文本与代码的数值必须同源：tooltip 里的数字从 %s 传入、取自同一组常量，不要在两处各写一份；改平衡只改常量
